# List Available Parallelized `landscapemetrics` Functions

Get a vector with names of functions available in `parallel.lsm`.
Functions are created when the package is loaded and will differ based
on what version of `landscapemetrics` is used. See
[`parallel.lsm()`](https://oxyppgyn.github.io/parallel.lsm/reference/parallel.lsm.md)
for arguments specific to the parallel versions of these functions.

## Usage

``` r
list_parallel.lsm()
```

## Value

A vector.
